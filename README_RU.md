# Tokyo Ghoul RPG — Forge 1.20.1

**Версия: 2.6.0 — Final Ghoul**

Мод для Minecraft Java Edition 1.20.1 на Forge 47.2.0. Требуется Java 17.

## Сборка

### GitHub Actions
1. Загрузите содержимое проекта в репозиторий GitHub.
2. Откройте **Actions → Build Tokyo Ghoul RPG 2.6.0**.
3. Запустите workflow вручную (**Run workflow**) или сделайте push в `main`/`master`.
4. После зелёной сборки откройте завершённый workflow и скачайте artifact **TokyoGhoulRPG-2.6.0**.

### Windows
Запустите `BUILD_WINDOWS.bat`. Скрипт использует Java 17 и при необходимости скачивает Gradle 8.8.

### Linux
Используйте `BUILD_LINUX.sh` с установленными Java 17 и Gradle 8.8+.

## Важно

Это исходники мода. Папки `build/`, `.gradle/`, IDE-файлы и готовые JAR в репозиторий не входят.

Игровые ресурсы 2.6.0 включают обновлённые 3D-кагуны, анимации движения/атаки/рывка/грейпла, текстуры кагунов и Quinque, NPC-ресурсы и звуки.
